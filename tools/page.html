🧩 个人配置生成器

本页离线运行，内容不会上传到任何地方
用法：① 第一次使用：填好带 * 的项，其他点「✨ 空白项一键生成」→「⬇️ 导出 .env」。② 以后修改：「📂 打开旧文件」→ 改要改的那一格 → 重新导出。
导出的文件包含密码和密钥，只保存在你自己的网盘、U 盘或密码管理器里。

📱 客户端：订阅地址 + 分流规则文件

根据上面填的内容自动生成。节点从订阅来；规则文件不含任何密码，可以放心保存。
订阅地址Clash 和小火箭用同一个
（填好域名、订阅端口、订阅路径、订阅 ID 后显示）
和 3x-ui 面板里显示的订阅地址相同。Clash Party 导入时会自动拿到 Clash 格式（含 PROXY 策略组），小火箭拿到普通节点格式。地址和二维码都相当于密码，别截图外发。
分流规则文件
已包含「分流名单（追加）」里填的域名：追加直连放在金融直连段；追加住宅在两端走代理，VPS 端走住宅。
怎么用
Mac · Clash Party
  1. 「订阅管理」→ 粘贴订阅地址 → 导入。
  2. 「覆写」→ 导入下载的 → 绑定到这个订阅并启用（旧版本覆写停用）。
  3. 代理组 PROXY 选 （自动分流，默认就是第一个）。
iPhone · 小火箭
  1. 首页右上角「＋」→ 扫描二维码（或粘贴订阅地址）。
  2. 「配置」→ 导入下载的 （用隔空投送或「文件」App）→ 点它 →「使用配置」。
  3. 首页选 节点（自动分流）。
