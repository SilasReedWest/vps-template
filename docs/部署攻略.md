# 部署攻略

> 适用：本仓库模板（3x-ui v3.10.2 + Xray v26.6.27 + Reality + 住宅 IP 分流）
> 读者：不懂技术也能照做。全程大约 30 分钟，其中真正要动手的只有 5 处。

---

## 0. 一张图看懂

```
网页工具（离线） ──生成──▶ 你的 .env（个人信息全在这里，自己保管）
                                │
         VPS 上运行一条命令 ◀────┘ 粘贴 .env
                │
     自动完成：BBR / SSH / 备份 → 域名解析 → 证书（域名 + IP）→ 本机伪装网页 → 装 3x-ui → 写入节点/路由/住宅出口 → 验收
                │
     客户端：导入订阅 + 导入规则文件（网页工具「📱 客户端」页下载）
```

| 东西 | 放在哪 | 含密码吗 |
|---|---|---|
| 本仓库（模板、脚本、网页工具） | GitHub 公开仓库 | ❌ 不含任何个人信息 |
| `.env` | 你的网盘 / U 盘 / 密码管理器 | ✅ 含全部密钥，**不要上传 GitHub** |
| 规则文件 `rules4.x.yaml` / `myconfig4.x.conf` | 电脑、手机 | ❌ 不含密码 |
| 订阅地址 / 二维码 | 只在客户端里 | ✅ 相当于密码 |

## 1. 必须自己完成的步骤（只做一次）

| # | 要做的事 | 说明 |
|---|---|---|
| 1 | **买 VPS**，系统选 **Ubuntu 24.04**（Debian 也行） | 记下 IP 和 root 密码。脚本只支持 Ubuntu / Debian |
| 2 | **买一个域名并接入 Cloudflare** | 用一个子域名，例如 `node.example.xyz`。必须是**灰云（仅 DNS）** |
| 3 | **（可选）生成 Cloudflare 令牌** | 见第 2 节。填了就不用手动改 DNS，以后换 VPS 也自动改 |
| 4 | **（可选）买静态住宅 IP（SOCKS5）** | 不需要住宅出口就在网页工具里把「启用住宅出口」选 `no` |
| 5 | **用网页工具生成 `.env`** | 打开 `tools/配置生成器.html` → 填域名 → 粘贴住宅 IP → 选 SSH 登录方式（见 3.0）→ 「✨ 空白项一键生成」→「⬇️ 导出 .env」。「伪装模式」保持默认 `self`，其他伪装相关的格子都不用填 |

> **不填 Cloudflare 令牌时**：部署前先在 Cloudflare 里添加一条 A 记录：名称 = 你的子域名，内容 = VPS 的 IP，代理状态 = **灰云**。
>
> **80 端口**：默认的偷自己模式要用 80 端口申请和续期 IP 证书，必须能从外网访问。DMIT 默认就是通的，什么都不用做；只有服务商后台有「安全组 / 防火墙」的，才需要在后台放行 TCP 80。

### 伪装模式是什么（不用操作，了解即可）

别人探测你的服务器时，要让它看起来像一个普通网站。默认的 `self`（偷自己）是这样做的：

| | 说明 |
|---|---|
| 伪装成什么 | 服务器自己的一个普通 HTTPS 网页，证书是 Let's Encrypt 签给 **VPS 的 IP** 的正规证书 |
| 谁来做 | 安装脚本全自动：申请证书、搭网页、设置开机自启、每 6 小时检查一次、到期前 3 天自动续期 |
| 好处 | 不依赖外部网站（外部网站停运、改配置都影响不到你）；不会把别人的连接转发出去（DMIT 防滥用问题不存在） |
| 域名还用吗 | 用。面板、订阅、备用节点还是用域名（证书 90 天）——这样换 IP 时订阅地址不变 |

另一个选项 `external`：伪装成 VPS 附近的外部网站 + 本机过滤（作者第一台 VPS 用的旧方案）。两种可以随时切换：网页工具改「伪装模式」→ 重跑安装 → 客户端刷新一次订阅。

## 2. Cloudflare 令牌（可选，推荐）

1. 登录 Cloudflare → 右上角头像 →「我的个人资料」→「API 令牌」→「创建令牌」。
2. 选模板 **「编辑区域 DNS」** →「使用模板」。
3. 「区域资源」选：包括 → 特定区域 → **你的域名**。其他不要动。
4. 「继续以显示摘要」→「创建令牌」→ 复制那串令牌，粘到网页工具「Cloudflare API 令牌」一格。

| 这个令牌能做 | 不能做 |
|---|---|
| 改这一个域名的 DNS 记录 | 改账户、看账单、动其他域名 |

泄露了：回到同一页面点「轮换」或「删除」即可，旧令牌立刻失效。

## 3. 开始部署

### 3.0 选 SSH 登录方式（网页工具「服务器登录（SSH）」，二选一）

| | `password`（默认） | `key`（密钥） |
|---|---|---|
| 怎么登录 | root + 服务商给的密码 | 只能用你设备上的「私钥」登录，密码登录关闭 |
| 安全性 | 密码够长基本没事，但全网机器人会天天来猜 | 别人猜不到，机器人白跑 |
| 要准备什么 | 什么都不用 | 先生成一对密钥，把「公钥」填进网页工具 |
| 私钥丢了怎么办 | — | 用服务商后台的 VNC / 控制台登录（不经过 SSH），运行 `rm /etc/ssh/sshd_config.d/01-vps-template.conf && systemctl reload ssh` 恢复密码登录 |

**选 `key` 时怎么生成密钥（任选一种）：**

| 在哪生成 | 步骤 |
|---|---|
| Termius（手机 / 电脑都行） | 「Keychain（钥匙串）」→「+」→「Generate Key」→ 类型选 **ED25519** → 保存 → 打开这把钥匙 →「Export / Copy public key」→ 复制以 `ssh-ed25519` 开头的那一行。之后在 Termius 的主机设置里把这把钥匙选上 |
| Mac 终端 | 运行 `ssh-keygen -t ed25519 -C vps`，一路回车（愿意可以设一个密码短语）→ 运行 `cat ~/.ssh/id_ed25519.pub` → 复制输出的那一行 |

把复制的**公钥**粘到网页工具「SSH 公钥」，「登录方式」选 `key`。

> ⚠️ 只复制**公钥**（`.pub`、以 `ssh-ed25519` 开头）。私钥任何时候都不要粘贴到网页工具、聊天或服务器上。
> 第一次运行安装时还是用密码登录；脚本关闭密码登录后，**先别关当前窗口**，新开一个窗口用密钥登录，能登上再关。

### 3.1 登录 VPS
用 Termius（或任意 SSH 工具）连接：主机 = VPS 的 IP，用户 = `root`，密码 = 服务商给的密码。

### 3.2 运行一条命令
```bash
bash <(curl -Ls https://raw.githubusercontent.com/SilasReedWest/vps-template/main/deploy/install.sh)
```

### 3.3 把 .env 交给脚本（二选一）

| 方式 | 怎么做 |
|---|---|
| **A. 粘贴（最简单）** | 脚本提示「请把 .env 文件的全部内容粘贴进来」时：用文本编辑器打开 .env → 全选 → 复制 → 在终端里粘贴 → **先按回车，再按 Ctrl+D** |
| **B. 上传文件** | 用 Cyberduck 把 .env 上传到 VPS 的 `/root/`，然后运行：`bash <(curl -Ls https://raw.githubusercontent.com/SilasReedWest/vps-template/main/deploy/install.sh) /root/你的文件.env` |

> 脚本会把 .env 保存为 `/root/vps.env`（只有 root 能读），以后重跑时会问「发现上次的 /root/vps.env，直接使用？」，直接回车就行。

## 4. 安装过程对照表

脚本**只会问你一个问题**（就是上面那个「直接使用？[Y/n]」），其余全自动。屏幕上会依次出现 8 步：

| 步骤 | 屏幕显示 | 正常结果 | 如果失败 → 怎么办 |
|---|---|---|---|
| 1/8 | 读取你的 .env | 无提示，继续 | — |
| 2/8 | 下载模板 | `✅ .env 检查通过` | 「.env 有问题」：按提示用网页工具改那一格，重新导出再运行。（只有 external 模式会在这里自动挑伪装网站；挑不到时按第 7 节手动找一个填上） |
| 3/8 | 系统设置 | `✅ BBR：bbr`、`✅ SSH：…`、`✅ 每日备份：…` | BBR 失败不影响使用；SSH 报错时脚本已自动撤销，登录方式不变，按红字处理 |
| 4/8 | 检查域名 | `✅ Cloudflare：… → IP（灰云）` 或 `✅ 域名已指向本机` | 「令牌无效」：检查令牌；「找不到域名」：域名没加到 Cloudflare；「没有指向本机」：手动加 A 记录（灰云）后重跑 |
| 5/8 | 申请证书 | `✅ 域名证书…`、`✅ IP 证书已签发`、`✅ 本机伪装网页已就绪`、`✅ 证书自动续期：开机自动启动，每 6 小时检查一次` | 「IP 证书申请失败」：确认 80 端口能从外网访问（服务商后台有安全组的放行 TCP 80）后重跑；「nginx 启动失败」：80 端口被别的程序占了 |
| 6/8 | 安装 3x-ui | `✅ 面板运行中` | 运行 `journalctl -u x-ui -n 50`，把输出（打码后）发给会的人 |
| 7/8 | 写入入站、用户、节点名、路由、住宅出口 | 一串 `✅`，最后 `🎉 配置完成` | 按红字提示处理；改完 .env 直接重跑，**重跑是安全的** |
| 8/8 | 验收 | `✅ Reality 伪装正常（偷自己…）`、`✅ 不会转发到外部网站`、`✅ IP 证书还剩 X 天`、`✅ 开机自动启动：面板、本机伪装网页、证书续期`、`✅ Xray 运行中`、`✅ VPS 出口：US / Los Angeles / …`、`✅ 住宅出口：US / … / 住宅运营商` | 有 ❌ 的：重跑一次安装（重跑是安全的）；还不行把红字发给会的人。external 模式「伪装目标没有返回证书」：见第 7 节「换伪装网站」；「过滤没有生效」：不要使用，先排查；「住宅出口连不上」：检查住宅 IP 信息或是否到期 |

最后会显示面板地址、用户名、密码、订阅地址，同时保存在 `/root/vps-deploy-result.txt`；并提示用两个网页在手机、电脑上检测（见《[自检与出行清单](自检与出行清单.md)》）。

> ⚠️ 如果最后出现红字「上面有自动生成的项目」：用网页工具「📂 打开旧文件」打开你的 .env → 把那几项补进去 → 重新导出覆盖保存。否则下次重装会生成新值，客户端要重新导入。

## 5. 客户端设置

打开网页工具 → 「📂 打开旧文件」选你的 .env → 拉到最下面「📱 客户端」。

| 设备 | 步骤 |
|---|---|
| **Mac · Clash Party** | ① 订阅管理 → 粘贴订阅地址 → 导入 ② 覆写 → 导入 `rules4.x.yaml` → 绑定到这个订阅并启用（旧版本覆写停用）③ 代理组 PROXY 选 `DMIT-AUTO` |
| **iPhone · 小火箭** | ① 首页右上角「＋」→ 扫二维码 ② 配置 → 导入 `myconfig4.x.conf` → 点它 →「使用配置」③ 首页选 `DMIT-AUTO` |

**四个节点的用途**（名字是默认值，可在网页工具里改）：

| 节点 | 用途 |
|---|---|
| DMIT-AUTO | 日常用：按名单自动分，AI/社交/电商等走住宅，其余走 VPS |
| DMIT-VPS | 全部走 VPS 出口 |
| DMIT-RES | 全部走住宅出口 |
| DMIT-BACKUP | 备用（WebSocket）：主节点连不上时用 |

**验证**：选 DMIT-AUTO 打开 `https://browserleaks.com/ip`，显示的应是 **VPS 的 IP**；切到 DMIT-RES 再打开，显示的应是**住宅 IP**。验证完切回 DMIT-AUTO。

### 5.1 Clash Party 推荐设置（Mac，一次设好）

| 设置 | 位置 | 建议 | 原因 |
|---|---|---|---|
| 虚拟网卡（TUN） | 侧栏「虚拟网卡」 | **一直开** | Claude Code、Codex 这类命令行程序不一定走系统代理，TUN 在网卡层接管才兜得住 |
| 严格路由 | TUN 设置 →「严格路由」 | 开 | 运行时防止流量绕过 TUN |
| 开机自启 | 设置 →「开机自启」（可再开「静默启动」） | 开 | 缩短开机后没有代理的那几秒 |
| 模式 | 首页 | **只用「规则」模式** | 全局模式下所有流量交给 GLOBAL 组，它可能停在 DIRECT（全部直连）；国内银行也会被送到美国 IP |
| GLOBAL 保险 | 临时切到「全局」→ 代理组 GLOBAL 选 **PROXY** → 切回「规则」 | 做一次 | 万一误切全局，AI 流量也不会直连 |

**开机防"偷跑"**：Clash Party 没有"没启动就断网"的功能。把 Claude、ChatGPT、Codex 等敏感 App 移出「系统设置 → 通用 → 登录项」，等 Clash 图标出现后再手动打开。
以前遇到的"代理没启动就上不了网"只是系统代理残留的副作用，不走系统代理的程序照样能直连，不能当作保护。

**拔网线后没网**：如果 Wi-Fi 和有线来自同一台路由器，拔宽带后 Wi-Fi 也没网，这不是 Clash 的问题。换网卡时 Clash 会自动跟随（日志里通常 1 分钟内切好）；偶尔卡住就把 TUN 关了再开。

### 5.2 小火箭（iPhone）

- 不开 TUN 也没关系，小火箭本身就是 VPN 模式，接管全部流量。
- 某个国内服务开着梯子打不开、关了能开：多半是它的某个后台域名不在国内名单里，被送去了美国。按「[日志排查](日志排查.md)」找出域名，加进网页工具「追加：直连的域名」。

## 6. 版本说明（为什么要固定版本）

| 组件 | 固定版本 | 原因 |
|---|---|---|
| 3x-ui 面板 | **v3.10.2** | 全流程验证过（自动配置用到它的官方接口） |
| Xray 内核 | **v26.6.27** | v26.9 起服务端默认拒绝旧客户端，小火箭可能连不上 |
| Clash Party | 用**内置稳定内核** | 不要切换到 Alpha 内核 |

- 「最小客户端版本」默认**留空**。只有以后换成 v26.9 及以后的内核、并且出现客户端被拒时，才在网页工具里填 `1.8.2`。
- **升级规则**：任何版本号都先在测试机上跑一遍，确认正常再改 .env 重跑。不要在面板里直接点「更新」。
- 访问日志默认关闭（`XRAY_ACCESS_LOG=none`），错误日志级别 `warning`，日志里的 IP 自动遮盖（`maskAddress=full`）。要检查分流时按「[日志排查](日志排查.md)」临时打开，查完关掉。

## 7. 日常维护

所有修改都是同一个套路：**网页工具打开 .env → 改一格 → 导出 → VPS 上重跑命令**。

| 想做的事 | 改哪一格 | 客户端要做什么 |
|---|---|---|
| 换伪装网站（只有 external 模式需要；self 模式不会失效） | 把「伪装目标网站」**清空**，重跑时自动重新挑；自动挑不到再按下面手动找 | 刷新订阅 |
| 切换伪装模式（self ↔ external） | 「伪装模式」 | 刷新订阅 |
| 改 SSH 登录方式 | 「登录方式」/「SSH 公钥」 | 不用动 |
| 改每日备份保留天数 / 关闭 | 「每日自动备份保留天数」（0 = 关闭） | 不用动 |
| 换住宅 IP | 「住宅 IP」智能粘贴新的 | 不用动 |
| 加一个走住宅的网站 | 「追加：走住宅的域名」 | 重新下载规则文件导入 |
| 加一个直连的网站（如新银行） | 「追加：直连的域名」 | 重新下载规则文件导入 |
| 订阅地址泄露 | 「订阅 ID」点生成 | 重新导入订阅 |
| 节点密码泄露 | 「用户 UUID」点生成 | 刷新订阅 |

**（external 模式）自动挑选是怎么挑的**：先扫 VPS 所在的同一网段（找不到再扩大），要求支持 TLS 1.3 + HTTP/2、证书正规，优先「域名本身就解析到这个邻居 IP」的，其次看延迟。只做一次 TLS 握手，不发任何内容。

**（external 模式）手动找新的伪装网站**（自动挑不到时；3x-ui 面板里操作，只是借它的工具找一个候选，**不要在面板里保存**）：

1. 左边菜单点 **「入站」** → 在 `reality-main` 那一行点 **铅笔图标**（修改）。
2. 弹窗顶部点 **「安全」** 标签。
3. 在「目标」一行，点右边的 **「🔍 查找目标」** → 从结果里挑一个延迟低、能返回证书的网站，**只抄下域名**（例如 `example.com`，不要端口）。
4. 点右上角 **✕ 关闭弹窗，不要点保存**。
   - ⚠️ 「目标」那一格里的 `127.0.0.1:4431` 是防滥用过滤入口，**绝对不能改成别的网站**，否则 DMIT 防滥用整改失效。
5. 网页工具里把域名填进「伪装目标网站」→ 导出 .env → VPS 上重跑安装命令。脚本会自动同时更新 SNI 和过滤名单。

**每日自动备份（默认开启）**：每天服务器时间 04:30 把面板数据库、证书、`/root/vps.env` 打包到 `/var/backups/vps-template/vps-日期.tar.gz`（只有 root 能读），保留最近 7 份（网页工具里可改，0 = 关闭）。

从备份恢复（面板里误操作、升级出错时）：
```bash
ls /var/backups/vps-template/                       # 看有哪些日期
mkdir -p /root/restore && tar xzf /var/backups/vps-template/vps-2026-01-01.tar.gz -C /root/restore
bash /opt/vps-template/deploy/install.sh --restore-db /root/restore/x-ui.db
```

> 每日备份在 VPS 本机，**整台 VPS 没了它也没了**。部署成功后仍要用 Cyberduck / Termius SFTP 把 `/etc/x-ui/x-ui.db` 和 .env 下载到自己的网盘。换新机器时：先跑一次安装，再用上面的 `--restore-db` 恢复。

**从已经配好的服务器导出 .env**（比如以前是手动在面板里配的，没有 .env；或 .env 丢了）：
```bash
mkdir -p /tmp/vt && curl -fsSL https://codeload.github.com/SilasReedWest/vps-template/tar.gz/refs/heads/main | tar xz -C /tmp/vt --strip-components=1
python3 /tmp/vt/deploy/export-env.py && rm -rf /tmp/vt
```

| 它会做 | 它不会做 |
|---|---|
| **只读**打开面板数据库，导出域名、端口、路径、用户、Reality 密钥、节点名、住宅出口、比模板多出来的住宅域名、版本号、SSH 登录方式，写到 `/root/vps-export.env`（只有 root 能读） | 不改面板、不重启任何服务；屏幕上只显示摘要，不显示密码和密钥 |

导出后要自己补：**面板密码**（数据库里是加密的，导不出来；不补的话重装时会生成一个新密码）、Cloudflare 令牌（如果要用）、「追加：直连的域名」（只在客户端规则里）。补好后用网页工具打开、重新导出保存。

## 8. 断网应急

按顺序试：

| # | 情况 | 怎么办 |
|---|---|---|
| 1 | 主节点连不上，VPS 还活着 | 两端切到 **DMIT-BACKUP** |
| 2 | 所有节点都连不上，急用 | 手机插**境外流量卡**开热点（流量本身就在境外出口）。用热点时把 Clash / 小火箭关掉。这时金融 App 看到的是境外 IP，非必要先别登录 |
| 3 | 伪装网站失效（只有 external 模式会遇到） | 第 7 节「换伪装网站」（清空重跑即可） |
| 4 | VPS 的 IP 被封 / IP 质量差要换 | 见下表「换 IP、换机器时要动什么」 |

### 换 IP、换机器时要动什么

核心原理：客户端连的是**域名**，不是 IP；密钥、UUID、伪装网站都在 .env 里。所以只要 .env 不变，**客户端什么都不用动**。

| 情况 | VPS 上要做 | Cloudflare | 客户端 |
|---|---|---|---|
| 同一台机器，服务商只换了 IP | 重跑一次安装命令（回车用上次的 .env） | 有令牌：自动改；没令牌：手动把 A 记录改成新 IP（灰云） | **不用动**（self 模式下脚本会自动给新 IP 申请证书）。如果几分钟后还连不上：先刷新一次订阅，再把 Clash / 小火箭重启一下（清掉旧的解析缓存） |
| 重装系统，或换一台全新 VPS | 运行安装命令，用**同一份 .env** | 同上 | **不用动** |
| 换服务商（不是 DMIT） | 同上；可以顺便在网页工具里把节点名 `DMIT-*` 改掉 | 同上 | 改了节点名就刷新订阅，没改就不用动 |
| 域名被封（换新域名） | 网页工具改「完整域名」→ 重跑 | 新域名加 A 记录 | **重新导入订阅**（地址变了）；规则文件不用动 |
| 端口被封（换端口） | 网页工具改对应端口 → 重跑 | 不用动 | 刷新订阅 |

**额外检查两件事：**
- **住宅 IP 白名单**：如果你在住宅 IP 服务商后台设置过「IP 白名单」认证，要把新 VPS 的 IP 加进去。用「用户名 + 密码」认证（本模板默认）就不用管。
- **面板里手动改过、但 .env 里没有的设置**，新机器上不会有。所以任何长期设置都尽量通过 .env 改；实在需要，用 `--restore-db` 恢复旧数据库。

> 长住大陆的定期检查和更细的应急顺序见《[自检与出行清单](自检与出行清单.md)》。
>
> 应急上网前就准备好：.env、`x-ui.db` 备份、网页工具（离线文件）都存在手机能打开的网盘里。
