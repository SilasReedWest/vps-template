# 自检与出行清单

> 两件事：① 部署完、换节点后，用两个网页确认「没泄露、出口对」；② 长住大陆，定期检查一遍，断网时知道先做什么。

---

## 1. 为什么要在设备上用网页检测

安装脚本跑在 VPS 上，**只能看到服务器这一侧**（结尾会显示：Reality 伪装、防滥用过滤、Xray 是否运行、VPS 出口和住宅出口的国家 / 城市 / 运营商，不显示 IP）。

手机、电脑有没有泄露真实 IP、DNS、WebRTC，**只能在设备上打开网页测**。客户端导入订阅后，在 **Mac 和 iPhone 上各打开一次**，节点选 **DMIT-AUTO**。

---

## 2. ip.net.coffee/claude —— 一页看全部出口

网址：`https://ip.net.coffee/claude/`

它的原理：页面同时去问好几个网站「你看到我的 IP 是多少」，再把结果放在一起对比。

| 页面上的项目 | 它问的是谁 | 我们的方案下应该显示 | 不对时说明什么 |
|---|---|---|---|
| Claude 看到的 IP | `claude.ai`（Cloudflare 回显） | **住宅 IP**（美国住宅宽带运营商） | 显示 VPS / 机房 IP → 住宅分流没生效，或节点选成了 DMIT-VPS；显示国内 IP → 客户端没走代理 |
| 一般海外网站看到的 IP | `1.1.1.1`（Cloudflare 回显） | **VPS 的 IP**（DMIT） | 这是正常的：一般网站走 VPS，只有名单里的走住宅 |
| 国内网站看到的 IP | ip138 / ip.cn | **国内 IP**（你本地宽带 / 手机流量） | 这是正常的：国内网站直连 |
| IP 信任分（风险评分） | 网站自己的接口，给 Claude 那个出口打分 | **≥ 70 分** | 明显偏低 → 住宅 IP 质量变差，考虑找服务商换一个 |
| DNS 泄露 | 测试你的域名解析服务器在哪 | **不在中国** | 出现中国的 DNS → 检查 Clash 是否开着 TUN、小火箭是否用的我们的配置 |
| WebRTC | 浏览器的实时通信接口 | 电脑上：**VPS 的 IP** 或不显示；**不应出现国内 IP** | 出现国内 IP → 浏览器绕过了代理，见下一节 |

## 3. browserleaks.com/webrtc —— 专门查 WebRTC

网址：`https://browserleaks.com/webrtc`

| 项目 | 应该显示 |
|---|---|
| RTCPeerConnection | ✔（浏览器支持，正常） |
| Public IP Address（公网 IP） | **VPS 的 IP**，或者不显示 |
| 不应该出现 | 任何国内 IP |

出现国内 IP 时：Mac 上确认 Clash Party 的 **TUN 模式开着**（系统代理管不到 WebRTC 的 UDP）；iPhone 上 Safari 一般不会泄露。

---

## 4. 定期检查（长住大陆，建议每月一次，出远门前必做）

| # | 检查项 | 在哪看 | 打勾 |
|---|---|---|---|
| 1 | VPS 续费日期、是否开了自动续费、账户余额 | 服务商后台 | ☐ |
| 2 | 住宅 IP 到期日 | 住宅 IP 服务商后台 | ☐ |
| 3 | 域名到期日 | 域名注册商 / Cloudflare | ☐ |
| 4 | 本月剩余流量（每月重置日见 .env） | 面板首页，或订阅里显示的流量 | ☐ |
| 5 | **两个节点都能用**：DMIT-AUTO、DMIT-BACKUP 各切过去打开一次网页 | 客户端 | ☐ |
| 6 | **用手机流量测一次**（关掉 Wi-Fi）：有的网络封得比家里严 | iPhone | ☐ |
| 7 | 跑一次 ip.net.coffee/claude，结果和第 2 节一致 | 手机 + 电脑 | ☐ |
| 8 | `.env` 和 `x-ui.db` 的备份在**手机能打开的网盘**里，而且是最近的 | 网盘 | ☐ |
| 9 | 备用机场订阅**还没过期、能连上** | 客户端 | ☐ |
| 10 | 离线网页工具（`配置生成器.html`）存在手机里 | 手机文件 App | ☐ |

> VPS 上的每日自动备份（`/var/backups/vps-template/`）防的是误操作和升级出错；**整台 VPS 没了它也没了**，所以第 8 项仍然要做。

---

## 5. 出问题时先做什么

| 情况 | 先做 | 再做 |
|---|---|---|
| 换了 Wi-Fi（酒店、公司、商场）就连不上 | 切手机流量试一下 | 切到 DMIT-BACKUP |
| 主节点连不上，其他网络也不行 | 切到 DMIT-BACKUP | 打开备用机场，登录 VPS 看安装验收结果（重跑安装命令，看第 8 步） |
| 所有节点都连不上 | 先用备用机场上网 | 用国内的 TCP Ping 工具测 VPS 的 443 端口：国内全不通、国外通 = IP 被墙 → 按《部署攻略》第 8 节换 IP |
| 安装验收提示「伪装目标没有返回证书」 | 网页工具里把「伪装目标网站」清空 | VPS 上重跑安装命令，会自动重新挑一个 |
| Claude / ChatGPT 提示地区不支持 | 跑一次 ip.net.coffee/claude，看 Claude 那一行是不是住宅 IP | 不是住宅：确认节点是 DMIT-AUTO；是住宅但分数低：联系住宅 IP 服务商 |
| 国内银行 / 支付 App 报异常 | 临时关掉梯子再用 | 把那个 App 的域名加到「追加：直连的域名」 |
| 什么都不行、急用 | 手机插**境外流量卡**开热点（用热点时关掉 Clash / 小火箭） | 金融 App 这时看到的是境外 IP，非必要先别登录 |
