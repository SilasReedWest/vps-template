## 改规则的流程

1. 改 `rules/client-clash.yaml` 和 `rules/client-shadowrocket.conf`（两端同口径，保留 `@@EXTRA_DIRECT@@` / `@@EXTRA_PROXY@@` 标记，文件头版本号一起改）。
2. 住宅名单改 `rules/vps-residential.txt`，同步 `docs/手动配置参考-住宅路由规则.md`。
3. `python3 tools/build.py` 重新生成网页工具。
4. 用 Mihomo `-t` 校验 Clash 规则，用 `node` 跑一次 `tools/client.js` 确认标记都被替换。
5. 提交。

## 已定的设计决策（不要再反复讨论）

- 客户端只分直连 / 代理；住宅还是 VPS 由服务器决定。
- 国内服务、国内及港澳新金融支付直连；PayPal、Wise 等按账户所在地直连。
- 第三方通用反欺诈 / 客服 / 统计服务（ThreatMetrix、LivePerson、AppDynamics、Tealium、Optimizely 等）**走代理**；国内金融 App 因此出问题时临时关梯子。
- 加密货币交易所走代理。
- Google / YouTube / Meta / Discord 走 VPS；AI、X、Reddit、美国电商、海外支付平台、美国流媒体走住宅。
- 微信 ASN 132203 直连；苹果 17.0.0.0/8 直连；Copilot 走代理（VPS 出口）。
- 不启用广告拦截规则集（会误伤 AI 服务的统计子域名）。
- 只用规则模式；TUN 常开；访问日志平时关闭（`none`），排查时临时打开。
- Reality 防滥用过滤（4431 入站 + 第 2、3 条路由）不能删。
