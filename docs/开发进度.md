## 改规则的流程

1. 改 `rules/client-clash.yaml` 和 `rules/client-shadowrocket.conf`（两端同口径，保留 `@@EXTRA_DIRECT@@` / `@@EXTRA_PROXY@@` 标记，文件头版本号一起改）。v2rayN 不用改，网页工具自动从 Clash 模板转换。
2. 住宅名单改 `rules/vps-residential.txt`，同步 `docs/手动配置参考-住宅路由规则.md`。
3. `python3 tools/build.py` 重新生成网页工具。
4. 用 Mihomo `-t` 校验 Clash 规则，用 `node` 跑一次 `tools/client.js` 确认标记都被替换、`CLIENT.v2rayn` 输出的 JSON 能解析且条目数 = Clash 规则数 − PROCESS-NAME − IP-ASN 399358 − 1 + 微信 IP 段数。
5. 提交。

## 已定的设计决策（不要再反复讨论）

- 客户端只分直连 / 代理；住宅还是 VPS 由服务器决定。
- 国内服务、国内及港澳新金融支付直连；Wise 等按账户所在地直连。PayPal 自 4.5 起走代理 + 住宅（作者决定）。
- 第三方通用反欺诈 / 客服 / 统计服务（ThreatMetrix、LivePerson、AppDynamics、Tealium（含 tiqcdn.com）、Optimizely 等）**走代理**；国内金融 App 因此出问题时临时关梯子。
- PayPal / X 登录、支付时调用的 Sardine、PerimeterX、DataDome 等跟平台走住宅（4.6，避免同一次登录出现两个出口 IP）。
- 小火箭国内名单：China_Domain + Loyalsoldier `direct.txt` 大列表（4.6）；Mac 用 geosite cn。
- Reality 默认**偷自己 + Let's Encrypt IP 证书**（`REALITY_MODE=self`）：本机 nginx 只在 127.0.0.1 放伪装网页，80 只做证书验证；`serverNames` = [IP, 空字符串]（客户端不会把 IP 当 SNI 发送），订阅里用主机 SNI 固定写 IP；证书 `shortlived`，到期前 3 天续期，续期用 systemd 定时器（开机自启、Persistent、每 6 小时）。面板、订阅、备用节点继续用域名证书。外部网站 + 过滤保留为 `external`。用户要求：全自动、不增加任何手动步骤。
- 不加防火墙（ufw）：锁死自己的风险大于收益（用户决定）。
- SSH：仓库提供 password / key 两种，默认 password。
- 每日备份默认开启（7 份）。
- 加密货币交易所走代理。
- Google / YouTube / Meta / Discord / Saily 走 VPS；AI、X、Reddit、TikTok、美国电商、海外支付平台（含 PayPal）、美国流媒体走住宅。
- 平台配套的第三方（hCaptcha、Socure、Intercom、App 专属 Sentry 地址）跟着平台走住宅；通用反欺诈 / 统计服务不进住宅名单。
- 微信 ASN 132203 直连；苹果 17.0.0.0/8 直连；Copilot 走代理（VPS 出口）。
- 不启用广告拦截规则集（会误伤 AI 服务的统计子域名）。
- 只用规则模式；TUN 常开；访问日志平时关闭（`none`），排查时临时打开。
- external 模式下 Reality 防滥用过滤（4431 入站 + 第 2、3 条路由）不能删；self 模式没有这两条（共 9 条路由）。
- 4.7 起 STUN（UDP 3478 / 19302）走住宅，必须排在前置 VPS 规则（geosite:google）之前；住宅 SOCKS5 需支持 UDP。代价：其他海外网站的 WebRTC、少量网络电话中转也走住宅（作者接受）。
- Claude 的 Sentry 只写专属地址 `o1158394.ingest.us.sentry.io`，不整段加 sentry.io。
- Anthropic IP 段按官方 IP 页逐段写（160.79.104.0/21、153.61.208.0/20、153.61.224.0/22），不合并成更大的段；客户端另加 `IP-ASN,399358`（Xray 不支持 ASN）。
- Claude 以后新出的、名字不带 claude / anthropic 的域名：靠定期 `route-check.sh 1 claude` 发现走了 direct 的再补，不改架构。
- 4.9：`TRAFFIC_LIMIT_GB` 默认 0（不限）。作者 VPS 上 3x-ui 用户流量（205 GB）远大于 DMIT 后台（双向 110 GB ≈ 实际 55 GB），重置日设置正确，原因没查（可能是 11-11 没自动清零，或用户挂两个入站被重复计算）。用量以服务商后台为准；DMIT 超量只降速，面板上限反而可能误停用户。
- 4.9：Cloudflare 人机验证 `challenges.cloudflare.com` 所有网站共用，没有 Claude 专属地址；为了 Claude 登录 IP 一致继续走住宅。住宅挂掉时手动切 DMIT-VPS，切之前先关 Claude（写进自检清单和攻略第 8 节）。讨论过「验证类服务住宅挂了自动回落 VPS」（Xray balancer + fallbackTag），作者嫌复杂，否决。
- 4.9：Clash Verge Rev 的设置页（IPv6、DNS 覆写、TUN）优先于覆写文件，必须在设置页里设对，写进攻略 5.1。
- 兜底一律走代理（Mac `MATCH,PROXY`、小火箭 `FINAL,PROXY`）：认不出的网站宁可慢、偶尔打不开，也不直连露出国内 IP。代价是小的国内网站偶尔被送出去，靠定期看三端日志补进直连名单（4.9 的停车缴费页就是这样发现的）。新加的直连放在「已知国内域名直连」段末尾、`GEOSITE,cn` / China 规则集之前；IP 段放在第 1 节私网段后面。
- Windows 用 v2rayN（作者决定）；v2rayN 路由由网页工具从 Clash 模板自动转换（PROCESS-NAME 跳过，IP-ASN 132203 换成 `rules/wechat-ips.txt`），不单独维护；页面里保留 Clash Verge Rev 说明给其他用户。
