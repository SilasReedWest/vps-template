# ===== 安全防护说明：4431 入站（reality-filter）与第 2、3 条路由 =====
# ⚠️ 不要删除、停用或调整顺序。
#
# 背景：2026-08-26 DMIT 发布网络安全公告，确认其洛杉矶（LAX）机房部分客户服务器上的
# SNI 代理类程序被人有组织地利用，成为可匿名访问 Cloudflare 及其后的 OpenAI 资源的开放出口。
# 收到两次通知后仍受影响的服务器会被关机，严重的可能被终止服务并追偿费用。
# 公告：https://dmit-abuse-team-temp-security-response.dmit.com/
# 全文：https://telegra.ph/DMIT-August-26-Network-Security-Bulletin-08-29
#
# 本服务器此前曾因此被 DMIT 暂停过。之后加了这层过滤：
# - in-4431-tcp（reality-filter）入站只允许访问 <伪装目标>（第 2 条 → direct），
# - 该入站的其余一切流量全部屏蔽（第 3 条 → blocked）。
# 作用：即使有人用未授权连接冒用本机的 Reality 伪装/回落通道，也只能到达 <伪装目标>，
# 无法把本机当作通往任意网站的开放代理，从而避免再次被 DMIT 判定滥用而关机。
#
# 删除后果：本机可能重新变成开放 SNI 代理 → 流量被盗用、IP/ASN 信誉受损 → DMIT 再次关停。
# 若以后要修改 Reality 伪装目标（target / serverNames）或 <伪装目标>，先确认这两条规则同步调整。
# 3x-ui 中这两条规则的「评论」栏建议填写：DMIT 2026-08-26 Reality 防滥用，勿删
